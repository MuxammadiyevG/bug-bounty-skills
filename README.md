# bug-bounty-skills

Self-contained AI skill base for **authorized** bug bounty, pentest, and CTF work.

## [`bounty-operator/`](bounty-operator/) — the engagement skill base

An all-in-one operating brain that governs *how* an AI agent hunts (scope enforcement, recon,
system modeling, false-positive gating, honest severity, chaining, coverage, reporting) **and**
carries the depth in-repo: 24 web2 vuln-class playbooks, per-class payload arsenals, bypass tables,
disclosed-report patterns, enterprise attack matrices, and extended domains (web3, mobile, reverse
engineering, CI/CD, credential attack, malware, CTF). No external skills required.

See [`bounty-operator/README.md`](bounty-operator/README.md) for install and structure.

> **Authorized testing only.** Use only on assets in an active bug-bounty program, a contracted
> pentest, a CTF, or systems you own. Scope is enforced before any request.
